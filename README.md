# Studify

## Overview
Studify is a user-centric educational platform where users are assigned the **student** role by default upon registration. An **admin** user can log in to manage users, update roles, and oversee the platform's functionalities, including monitoring all chat interactions.

## User Roles
- **Student:** Default role for all new users.
- **Admin:** Has permissions to manage users, update roles, and monitor chats.

---

## Features
- User registration and authentication.
- Role-based access control.
- Admin dashboard for user management.
- Chat system with full message details saved, including timestamps and user info.
- Role updates managed by admin.
